# IntelliVision_clustering
Кластеризация изображений транспортных средств для проекта IntelliVision — Smart City/Transportation

**Источник**

https://www.kaggle.com/datasets/markhomeless/intellivision-case

## Постановка задачи

Один из ключевых проектов IntelliVision — Smart City/Transportation, система, обеспечивающая безопасность дорожного движения и более эффективную работу парковок. Для повышения ее эффективности необходимо автоматизировать определение дополнительных параметров авто на изображении:

* тип автомобиля (кузова),
* ракурс снимка (вид сзади/спереди),
* цвет автомобиля,
* другие характеристики.

Также необходимо автоматизировать поиск выбросов в данных (засветы и блики на изображениях, изображения, на которых отсутствуют автомобили и т. д.).

Предполагается, что разметку исходных данных можно эффективно провести с помощью методов кластеризации.

Имеется небольшой набор моделей свёрточных нейронных сетей, обученных на различных датасетах и решающих различные задачи от классификации изображений по цвету до классификации типов транспортных средств. База изображений была пропущена через каждую модель. Интерес для исследования представляет не выходной результат модели, а только промежуточное представление признаков (дескриптор), полученное на свёрточных слоях сети.

* `efficientnet-b7` — модель классификации с архитектурой EfficientNet версии 7. Предобучена на датасете ImageNet, в котором содержатся изображения более 1000 различных классов. Эта модель при обучении не видела датасета veriwiId. 
* `osnet` — модель OSNet, обученная для детектирования людей, животных и машин. Модель не обучалась на исходном датасете veriwiId.
* `vdc_color` — модель регрессии для определения цвета транспортных средств в формате RGB. Частично обучена на исходном датасете veriwild.
* `vdc_type` — модель классификации транспортных средств по типу на десяти классах. Частично обучена на исходном датасете veriwild.

Для всех вариантов дескрипторов нужно применить несколько алгоритмов кластеризации и сравнить полученные результаты. Сравнивать можно на основе метрик, визуализаций плотностей кластеров и по тому, насколько хорошо интерпретируются кластеры.

Дополнительная подзадача — найти выбросы среди изображений. Это могут быть изображения плохого качества, изображения с бликами или изображения, на которых нет транспортных средств и т. д.

**Основные цели**

1. Для каждого типа дескрипторов необходимо:
    * выполнить предобработку дескрипторов;
    * произвести кластеризацию изображений на основе их дескрипторов, подобрав алгоритм и параметры кластеризации;
    * сделать визуализацию полученных кластеров;
    * проинтерпретировать полученные кластеры — сформулировать, какие изображения попали в каждый из кластеров.
2. Сравнить между собой полученные кластеризации для каждого типа дескрипторов (по метрикам, визуализации и результатам интерпретации).
3. Выполнить автоматизированный поиск выбросов среди изображений на основе дескрипторов.

## Данные и их описание

```
IntelliVision_case
├─descriptors
    └─efficientnet-b7.pickle
    └─osnet.pickle
    └─vdc_color.pickle
    └─vdc_type.pickle
├─row_data
    └─veriwild.zip
├─images_paths.csv 
```

* В папке `descriptors` содержатся дескрипторы, полученные для каждого из изображений с помощью соответствующих нейронных сетей, в формате numpy-массивов, сохранённых в файлах pickle.
* В папке `row_data` содержится zip-архив с исходными изображениями автомобилей. Архив содержит десять папок с изображениями, пронумерованных от 1 до 10. Каждая папка содержит подпапки, обозначенные пятизначными цифрами, например 36191. В каждой из таких подпапок содержатся фотографии одного конкретного автомобиля с разных ракурсов, снятые с помощью дорожных видеокамер.
* В файле `images_paths.csv` представлен список из полных путей до изображений.
